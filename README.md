---

## 1️⃣ USER ROLES
Total **3 role utama (fix)**

### 1. Reader
User default setelah register.

**Permissions:**
- Browse & read stories  
- Read chapters  
- Bookmark stories  
- Like & comment per chapter  
- Follow writers  
- Manage profile & reading history  

---

### 2. Writer
Upgrade dari Reader.

**Additional permissions:**
- Create & manage stories  
- Create, edit, publish chapters  
- Draft & scheduled publish  
- View story & chapter analytics  
- Respond to comments  
- Manage story metadata (genre, tags, cover)  

---

### 3. Admin
Role tertinggi (superuser).

**Permissions:**
- Manage all users (reader / writer / admin)  
- Approve / suspend writer accounts  
- Moderate stories, chapters, comments  
- Handle reports (plagiarism, abuse, spam)  
- Manage genres & tags  
- View platform analytics  
- Feature / highlight stories (trending, editor’s pick)  


## 3️⃣ CORE FEATURES (FULL SCOPE)

### 📖 Reader Features
- Story & chapter reading  
- Dark / light mode  
- Font size & line spacing control  
- Auto-save reading progress  
- Bookmark & favorites  
- Like & comment per chapter  
- Follow writers  
- Personalized reading history  
- Share story/chapter (link + social)  

---

### ✍️ Writer Features
- Story creation (cover, synopsis, genre, tags)  
- Chapter editor:
  - Autosave  
  - Word count  
  - Draft & publish  
- Scheduled publishing  
- Series / season support  
- Reader engagement stats:
  - Views  
  - Likes  
  - Bookmarks  
- Comment moderation (own story)  
- Writer profile customization  

---

### 🧠 Discovery & Engagement
- Trending stories (algorithm-based)  
- New releases  
- Genre-based discovery  
- Editor’s pick (admin curated)  
- Recommendation (based on reading behavior)  
- Weekly highlights  
- Writer follow system (reader can follow writer updates)  

---

### 🛡️ Moderation & Safety
- Report system:
  - Story  
  - Chapter  
  - Comment  
- Content flagging  
- User suspension / ban  
- Age rating per story  
- Plagiarism detection (future / optional)  

---

### ⚙️ Platform / System Features
- Role-based access control (RBAC)  
- SEO-friendly URLs  
- Sitemap & indexing  
- Analytics (read time, retention)  
- Notification system (future):
  - New chapter  
  - Followed writer updates  
- Email verification & password reset
